구글 시트 연동 및 설정

Google Sheets에 붙여넣을 스크립트 배포 URL입니다. 비워두면 브라우저 내부 다이어리에만 안전하게 보관됩니다.

구글 시트 1분 연동 코드 & 연결 해결법
⚠️ 연결 실패 시 필수 확인 3가지:
1. 배포 시 [액세스 권한]을 반드시 모든 사용자(Anyone)로 설정했나요? (로그인 필요 없음에 체크)
2. URL 끝부분이 /exec 로 끝나는지 확인하세요. (/edit은 안 됩니다)
3. 스크립트 코드를 수정했다면 반드시 [배포 관리 > 연필(수정) > 새 버전]으로 다시 배포해야 반영됩니다!

1. 구글 시트 > 상단 메뉴 확장 프로그램 > Apps Script를 클릭합니다.

2. 기존 코드를 모두 지우고 아래 개선된 코드를 붙여넣은 뒤 저장(Ctrl+S)합니다:

function doPost(e) {
  try {
    var ss = SpreadsheetApp.getActiveSpreadsheet();
    var sheet = ss.getActiveSheet();
    
    // 시트가 비어있으면 헤더 자동 생성 [시간, 날씨, 일기 내용]
    if (sheet.getLastRow() === 0) {
      sheet.appendRow(["시간", "날씨", "일기 내용"]);
      sheet.getRange(1, 1, 1, 3).setBackground("#dcfce7").setFontWeight("bold");
    }
    
    // JSON 데이터 파싱 (POST 본문 처리)
    var raw = e.postData.contents;
    var data = JSON.parse(raw);
    
    sheet.appendRow([
      data.time || new Date().toLocaleString(),
      data.weather || "",
      data.diary || ""
    ]);
    
    return ContentService.createTextOutput(JSON.stringify({status: "success"}))
      .setMimeType(ContentService.MimeType.JSON);
  } catch(err) {
    return ContentService.createTextOutput(JSON.stringify({status: "error", message: err.toString()}))
      .setMimeType(ContentService.MimeType.JSON);
  }
}

function doGet(e) {
  return ContentService.createTextOutput("✅ 보이스 다이어리 웹앱이 정상 작동 중입니다! (URL 정상)");
}

3. 상단 배포 > 새 배포 (유형: 웹 앱)
- 다음 사용자 권한으로 실행: 나(내 계정)
- 액세스 권한이 있는 사용자: 모든 사용자(Anyone)
- 배포 후 생성된 웹 앱 URL (끝이 /exec)을 복사하여 위 칸에 넣으세요.
